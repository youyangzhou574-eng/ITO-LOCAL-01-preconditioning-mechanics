## 新分支的物理路线

| 项目 | 既有 V2 | Pro 新断裂分支 |
|---|---|---|
| 薄膜 | 150 nm，既有壳与 TRACK 流程 | 150 nm，有限变形 solid-shell AT2 UEL |
| 初始形貌 | 保留冻结的缺陷和材料身份 | 平面，无预置缺口或弱带 |
| 端部长度 | 132 → 129.36 um，约束回缩 | 132 → 120 um，完全释放目标 |
| 支撑 | 底部支撑保留 | 最小刚体约束，侧向允许响应 |
| 界面 | 理想结合 | 第一版仍完美粘接 |
| 断裂 | 未包含 | 膜内 AT2，非界面脱粘 |

建议将新分支独立实施，以 Pro 的有限变形 solid-shell AT2 为主候选；XFEM、UMAT 热类比、PF-CZM 根据要回答的问题作为基准或对照。不同能量、应力度量、2D/3D、串并行与输出层不直接拼接。

**R2 请判断：**上述物理路线是否符合目标；首版保留完美粘接是否合理；初始平面无缺口条件下如何解释分叉与缺陷敏感性。原方案材料卡、Gc 等仍为方法假设，不称本工艺实测标定。

## 验收定义和阈值

下列数字已出现在 Pro 方案中，按原文件范围列出，尚不是本次 skill 建设新制定的容差。请结合源码可计算性和作者基准证据审阅。

| 内容 | Pro 已提出的指标 | 审阅重点 |
|---|---|---|
| PDMS 状态转移 | 坐标 max 误差 <=1e-7 mm；应力相对 L2 <=1e-3 | 同时给绝对量、分量、参考零场，并检验切线和小增量功 |
| 膜无应力出生 | 平面拟合残差 p99 <=5e-7 mm；应力各独立分量绝对 p99 <=0.5 MPa；应变各分量 p99 <=5e-6 | p99 不覆盖全部极值；请判断是否另需最大值及异常位置报告 |
| 耦合收敛 | 各场归一残差目标 <=1e-6；最后迭代 max abs Delta d <=1e-6 | 归一化、绝对残量、DOF11 与 actual accepted state；不能只看机械收敛或 exit0 |
| 能量闭合 | 总增量收支残差/E_ref <=1% 为目标；数值耗散/E_ref 目标 <=2%，>5%不作物理资格通过 | E_ref 固定定义；断裂能不属于应被压低的人工耗能；UEL 与原生能量不重复记账 |
| P1 作者基准 | 峰值载荷目标误差 <=5% | 参考曲线可信度、数字化误差、同一问题定义；不能制造精确参考值 |
| P2 导数核验 | 远离谱分裂拐点的相对导数误差目标 <=1e-5 | 扰动步长扫描、同一接受态；拐点单独处理 |
| P4 网格 | ell 固定，两档间峰载/总功/裂纹能变化 <=5%可称这些全局量稳定 | 不代表每条裂纹、密度或片段统计收敛，更不回填 V2 的科学资格 |
| 损伤观察 | d>=0.5 局部带；d>=0.95 高损伤连通带，同时比较 0.90/0.95/0.99 | 观察阈值不是材料强度；first d>0 不是第一条裂纹 |

E_ref 原定义是 `max(U_PDMS_birth + U_ITO_birth, max abs Delta W_ext, Gc*t_f*L_0)`，用于 W1 内以 BIRTH_HOLD 末态为起点的增量收支。分母与取值范围在首个结果前写入配置；近零段报告绝对量和不可评价状态。详见原方案第 7 节，不能用本摘要代替全部条款。

**R3 请判断：**以上指标在拟采用接口与实际输出中能否直接计算；是否需要增加基于最大值的局部异常门、残量尺度定义或数据缺失处理。确认后按新分支冻结；旧 V2 保持原科学状态。
