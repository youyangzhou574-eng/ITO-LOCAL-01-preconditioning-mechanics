# 通用建模与分析

## 模型身份与几何

用稳定的 part/instance/set/surface 名称与节点/单元标签表达物理区域；避免依赖易漂移的几何索引、掩码和未核验 findAt。查维度、厚度、装配变换、共享节点、连接、局部坐标、法向和壳偏置。导入/网格更改后验证集合实际非空、覆盖与数量。

采用薄膜、膜、壳、连续壳或实体，应由需要保留的厚度应力、弯曲、剪切、接触和失效机制决定。壳与实体不能仅为降成本互换。重叠可视化单元可能贡献刚度/质量/能量，必须量化其影响。

## 材料与初始状态

记录参数来源、应变/应力度量、温度/速率依赖和适用区间。塑性数据检查真应力、塑性应变及首点；超弹材料检查试验加载模式与近不可压缩处理。近不可压缩可考虑匹配的 hybrid/mixed 形式，不能把 ν 改小作为无说明的修复。

复合层合板记录铺层、方向、各层厚度、截面点、损伤起始和演化；固化/热残余应力另列温度、收缩、固化度和参考状态。S-N、应变寿命和裂纹增长寿命是不同问题，疲劳参数需来自相应材料及工况。

分阶段激活、预应力导入、应力自由出生和重启分别核查：几何参考构形、继承变量、时间与载荷连续性、活跃集合和输出。单纯清零 stress 不一定建立正确的自然构形。

## 网格与边界

- 比较自由度、积分规则、畸变/锁定/hourglass、长度尺度及成本；不默认 C3D8R 适合所有问题。
- 初始与变形后 Jacobian/体积的检查覆盖声称范围内的积分点。检查节点顺序、翻转单元、壳法向和厚度积分。
- 支撑首先去除刚体模式；每个额外约束应有物理依据。对称、周期、底面固定或横向约束都会改变起皱/断裂模式。
- Tie、共享节点、硬/软接触、摩擦和 CZM 分别表达不同物理关系。不能由“橡胶”直接推断软接触；摩擦系数与初始调整量不是通用常数。
- 反力平衡、接触压力/开闭/滑移、穿透和约束能一起解释接触结果。初始调整、稳定化和接触算法改变需记录影响。

## 分析程序选择

| 程序 | 判断依据与核查 |
|---|---|
| 静态非线性 | 有限转动/应变、接触、材料非线性和路径稳定性；载荷随步时间变化并不自动需要动力学 |
| 隐式动力学/准静态 | 物理或数值时间尺度、惯性与耗散；看完整历程及速度敏感性 |
| Explicit | 波传播、冲击、接触复杂度、最小元素稳定步长与总成本；质量缩放改变惯性，应独立论证 |
| 模态/特征屈曲 | 基态、约束、模态与负特征值含义；特征屈曲不等于非线性后屈曲 |
| Riks | 平衡路径适配、控制方式、材料/接触与用户单元能力；不能把普通 UEL 直接宣称支持 |
| 热/热力耦合 | 单向温度映射可使用顺序耦合；存在反馈时评估双向耦合。普通结构元素也可承受预定义温度产生的热应变 |
| 疲劳/优化 | 正确定义循环、均值效应、目标量、材料数据、约束与独立验证；优化器不能替代有效性检查 |

不按“10 ms/100 ms”固定分界选求解器。不以更小步长、稳定化或质量缩放代替根因诊断。输出由目标量反推；完整覆盖已承诺的帧/积分点时不得擅自抽样缩减。
