# 断裂与失效方法选择

先明确破坏发生在材料内部还是界面、裂纹路径是否已知、是否需要真实分离/接触、是否已有裂纹、有限变形与塑性范围，以及可用材料数据。

| 方法 | 适用问题 | 核心数据与限制 |
|---|---|---|
| 固定裂纹 K/J/CTOD、contour/domain integral | 给定裂纹的驱动力/韧性比较 | 裂纹前缘、坐标、裂尖网格、路径/轮廓稳定性；K 的小规模屈服、J 的材料与载荷路径假设分别核验 |
| VCCT | 预定义界面裂纹路径 | Mode I/II/III 能量释放率与混合模态法则；不自动发现任意膜内裂纹 |
| Cohesive element / surface CZM | 已知界面或允许预布置黏聚面的分离 | 法向/切向强度、Gc、混合模态、刚度、网格/过程区、压缩接触与重接触 |
| XFEM | 兼容元素和程序下的材料内部裂纹 | 富集域、初始裂纹或起裂准则、演化、方向、局部坐标、版本限制 |
| 连续损伤/单元删除 | 指定材料失效机制 | 特征长度正则化、能量、删除后的接触/质量；损伤变量不等于几何开口 |
| 相场 AT1 / AT2 / PF-CZM | 弥散裂纹演化、分叉等 | 具体泛函、强度/长度尺度、不可逆性与求解法；三者不能互换 |
| 疲劳断裂 | 循环驱动裂纹增长/寿命 | 循环幅与均值、增长律或疲劳退化；单调拉伸代码不自动具备疲劳能力 |

## XFEM 准则的准确含义

MAXPS 是最大主应力准则；MAXPE 是最大主应变准则，不能把“MAXPE=延性材料”作为完整模型定义。QUADS 是名义应力/牵引的二次交互准则，不是“二次主应力”或仅剪切准则。起始准则必须与演化、局部方向和材料机制共同指定。[O5]

损伤起始、损伤演化、可见裂纹、完全分离和失去承载分别报告。满足 MAXPS 并不自动产生脱粘；完美 Tie 不会由于膜应力高而自行断开。

## 报告与材料转移

标定时把弹性/塑性或超弹参数、起裂强度、断裂能、混合模态律、黏性/速率、相场长度尺度分别列出。用一条全局载荷—位移曲线同时拟合多项参数可能不唯一；需要独立试验或可辨识性分析。AT2 中有效强度与弹性模量、Gc、ell 和具体形式相关，不把 ell 当成任意数值旋钮。

按机制选基准：界面 Mode I/II/混合模态可用对应 DCB/ENF/MMB 作者算例；体内裂纹可用选定论文的拉伸/剪切/弯曲基准。逐项匹配几何、平面条件、厚度、材料、缺口、载荷和测量定义；只复现相似裂纹图不构成定量验证。校准数据与验证数据分别说明。

裂尖应力奇异峰值不能作为网格收敛量或直接与一个应力许用值混比。光滑区域有限应力峰值与奇异峰值应先区分；不要笼统说“一切峰值都不能收敛”。

K/J 的路径独立性是需要检验的性质，不是软件变量名字带来的保证；有限应变、卸载、残余应力、非比例塑性、材料非均匀和边界邻近均须考虑。韧性、强度、速率和厚度/约束状态应与使用工况相符。

优先用原生功能满足问题；确需自定义相场或材料时进入 [子程序](user-subroutines.md) 与 [相场](phase-field-solid-shell.md)。软件选择属于实现，物理方法选择需要保留用户方案。
