## 结论与下一项

- 项目/分支/阶段：
- 本次已授权动作、依据及实际消费：
- 当前结果：什么已证实；什么未证实；一个具体下一动作。
- 需要用户决策：只有新增物理/权限/预算或真实阻塞；没有则写“不需要同义批准，按现有授权接续”。

## 源和实现

固定方案commit/路径、文献页/式号、作者源码及许可、项目改造、编译器/版本、INP/INCLUDE/源码hash。读了摘要还是全文要分开。提供公式—代码映射入口，不重复抄整本论文。

## 实际执行与状态

|层|状态|证据/覆盖|限制|
|---|---|---|---|
|技术|COMPLETE / FAILED / NOT_RUN|job/attempt、退出码、实际末接受增量|不得伪造未输出帧|
|身份|VERIFIED / UNRESOLVED|文件hash/元数据/标签|声明的范围|
|几何|VALID / INVALID / NOT_EVALUATED|detJ/位置/采样、前缀|不同于detF和接触检查|
|能量|QUALIFIED / FAILED / REFERENCE_UNRESOLVED|分项定义/参考/残差/窗口|不双算、不把裂纹能当人工|
|损伤|LOCALIZED_BAND / DIFFUSE / NONE / NOT_EVALUABLE|阈值/连通性/参考面积|不等于裂宽/电阻|
|标定|CANDIDATE_ONLY / CALIBRATED_WITH_SOURCE|实验或候选依据|可支持的结论|

列出原始异常与修复前后差异，不覆盖历史FAIL。SSH不可见单列CURRENT_UNKNOWN及最后真实观察时刻。

## 核心图表

真实XY损伤/三维表面、裂纹带或片段候选与释放进度、力—位移、分项能量。每图实际step/inc/frame、坐标、单位、变形倍数和色标；是否本地decode/view、是否接收端实际取得图片二进制分别记录。
