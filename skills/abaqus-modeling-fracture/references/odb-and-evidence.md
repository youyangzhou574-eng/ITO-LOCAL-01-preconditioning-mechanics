# 原生数据、几何、能量和裂纹证据

## 1. 先约定提取实体

每条数据绑定 `job_id/source_hash、step、native_increment、frame_index、time_basis/raw_time、branch、instance、element/node、IP/section/layer、componentLabels、坐标系、应力度量、位置与单位`。生产UEL还需接受态sidecar与原生ODB的映射，普通单元S/LE不能自动代表UEL。

源文件闭合后按同一读取字节算摘要并解码；NPZ所有声明成员CRC/shape/dtype/标签一致、禁pickle。读取侧完整可见不等于看过每幅图。科学修订写新目录，不修改原始时间、原FAIL/exit或历史清单。

## 2. 接受增量与时间表示

先由**同job/同step/同native increment**的真实已接受STA记录匹配，再用原始打印token的有效小数位/指数和浮点表示误差比较时间。区分step time与total time；同名step不能跨作业匹配。失败attempt、未输出增量不能补为场帧。重复冲突记录、无接受证据、初始frame0分别保留UNRESOLVED/初态证明需求，不能一律“未收敛”。

本包`match_frame_to_sta`接收已经正确解析的accepted rows；它**不是通用STA解析器**。依原token半个打印量子+binary32表示容差作兼容检查，仅在身份一致后使用。不证明ODB时间一定为float32，不改能量/力学门；目标版本有更精确元数据时用其显式规则。无需为可解释浮点表示差重跑求解。

## 3. 张量与截面

按完整标签提取11/22/12，不使用`[:3]`。标签为11,22,33,12,13,23时前三列没有12。未知量不补0；仅有S11/22/12只报告该基下平面内主值，不冒充三维主应力。应变工程剪切与张量剪切分别转换；PK2、Cauchy和局部/全局方向先统一再比较。

截面平均膜应力、膜力/厚度和上下表面应力不同；S4R截面点、solid-shell厚度IP、可视化覆盖单元分别映射。出生审计全分量/p99/最大值/覆盖与异常位置齐备。stress-free初态不能由小色标条纹或p99单独证明。

## 4. 几何有效性

`detJ = det(dx/dxi)`为几何映射，三维单位length³；`detF`为无量纲本构变形梯度行列式。原/当前同节点顺序的detJ比在相应几何定义下可辅助核查detF，但ANS/EAS增强应变F不应被这个比值替代。

先验证参考节点排序、局部/全局坐标、单位、仿射patch及刚体转动；再检查当前坐标。记录元素、局部采样位置和负值量级/相对参考J，不用abs(detJ)。原生积分点检查与附加中心/角点/2×2×2探针分开：本包HEX8探针不是C3D8RH或自定义UEL实际积分规则。有限点全正不等于全域无倒置、无重叠或解已可信。

已确认负J是几何FAIL，修时间匹配可增加“被评价”的帧，不能让既有负J消失。首个被观察到的负J不一定是历史最早物理失效。UNKNOWN打断已证明的有效前缀；以后单帧有效不重新拼接前缀。几何有效前缀也不等于能量/出生等全部科学条件有效。

## 5. 能量账本

建立同W1、BIRTH_HOLD末态起点的分项增量：原生PDMS储能、UEL膜储能、独立裂纹能、实际外功、人工/粘性项、所选程序存在的动能；模型加入界面后其物理耗能单列。每项注明定义、单位、参考体积、积分权重、原生槽/sidecar字段及是否已包含在ALLIE/ALLSE。

**断裂能是物理项，不是人工能量。**H是历史驱动不等于当前psi储能。UEL能源映射不清时ENERGY_REFERENCE_UNRESOLVED，不用global-minus猜出材料能量，也不把缺失ALLDC补零。已证实互斥完整分区下的余项可记录DERIVED_REMAINDER，但不改名native ITO输出或控制算法状态。

外功含所有施加的位移/转动、力/分布载荷和seed；相场伪温度的热类比输出不是物理热功。积分带符号并分别核对绝对量、分母和每段。只看终态KE低、work闭合或小数值耗散，不证明整个断裂过程准静态。

## 6. 裂纹、片段和形貌

AT2的`first d>0`报告为弥散损伤起始，不叫第一条裂纹。按计划同时观察0.90/0.95/0.99连通带敏感性，固定面积/体积基准、邻接方式和通过厚度的定义。上下面d均高不必然代表中间也贯通；检查实际厚度插值/积分。

裂纹密度给出有效观察区面积和长度提取算法；分辨率/阈值影响单列。可用高损伤带将承载区域分成候选连通片段，但不能直接称已物理分离的碎片，更不推出裂面间距、摩擦接触或电阻。完全粘接膜裂了仍由PDMS连接。

真实XY的d图、当前三维表面、参考材料坐标图互为补充。波长不是本断裂阶段必需PASS项；图需坐标/单位、状态、比例尺、色标、原始帧。局部自动色标不能把近零出生高度差渲染成皱纹证据。

## 7. 同状态比较与截线

沿同一branch、同物理参考比较。精确重复应变取最后原生样本只在单调分支内部；近重复不合并，反转不排序掩盖，释放/重拉同应变各自保留。仅在共同覆盖内插值标量，不外推、平移事件或平滑后再过原门。端点浮点差可单列为终态对照，但不能悄悄外推成同状态。

材料profile预先按参考网格拓扑或参考单元内坐标固定，当前时刻只跟踪同一材料点；不用当前y数值恰相等找线。空间插值需预定义支持单元及权重、证明覆盖，不根据图的清晰度换线。自交/非单调当前x、缺点或无效来源明确报错，不用排序制造曲线。

`python -m unittest discover -s tests -v`
