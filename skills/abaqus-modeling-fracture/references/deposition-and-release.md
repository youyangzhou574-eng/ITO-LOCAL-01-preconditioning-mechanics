# 预拉伸—平膜出生—释放断裂

依据当前计划而不是旧起皱分支。V1保持新W0→新W1导入路线，本skill不把它改成单作业激活；替代路线需要独立版本。[P，见文献模块]

## 每个材料的自然参考态

|状态|PDMS|ITO|最少见证|
|---|---|---|---|
|W0初态|裸基底自然态|不存在/不承载|几何、材料、单位|
|W0末态|预拉伸、储能、真实横向收缩|仍不承载|实际表面、F/应力状态、反力、参考坐标|
|W1出生|保留W0已变形状态及本构历史|在当前表面新生、平坦、d=H=0|界面坐标、膜全分量/应变、参考态、基底小增量切线|
|W1释放|夹具控制回缩、横向力学响应|相场从开始释放即启用|实际端距、两方向应变、弯曲、裂纹带、能量|

几何更新参考后，PDMS当前网格看起来“位移零”不表示裸材料F=I；清零应力不能替代正确自然构形。仅导入支持的PDMS原生单元，ITO UEL在W1新建。实际膜参考从W0真实顶面取，不从计划132 μm字符串构造虚假表面。[P]

## 出生核对配方

1. 原生集合一一匹配：顶面、膜底面、端面和材料；记录节点/面覆盖、最大偏差、未匹配。不要同时共享节点又重复施加Tie约束。
2. Solid-shell用几何给150nm厚度，朝真实表面外法向；不另加75nm中面偏置导致重复厚度。S4R的截面点规则不能照搬到UEL。
3. 仅位移传递；相场DOF不参与PDMS界面约束。检查无意新增的温度边界/导热系数。
4. 膜初态及BIRTH_HOLD：按全分量标签测应力/应变、d/H和参考平面。p99与最大值/异常位置一起输出；保持原数值门，不靠屏蔽边缘掩盖错误。
5. PDMS导入前后几何与应力连续后，还要做同基态微小增量试验，比较反力/能量增量；清零/误配内变量可能在初态应力相似而切线不同。
6. W0和W1全局ALLSE不强制相等；同W1从出生末态定义增量能量。缺自然参考能量的定义时ENERGY_REFERENCE_UNRESOLVED，不补常数。

## 释放边界与机制

本版位移控制端距 L(r)=Ld-r(Ld-L0)，Ld取真实W0末端距；标明相对PDMS原长工程应变和相对ITO沉积长度缩短量，二者不能混用。底面不整体固定，横向不锁死；只加独立的必要刚体约束并报告其反力。实际撤夹零外力版本另定。

近不可压缩裸基底单轴伸长1+p时，理想横向收缩(1+p)^(-1/2)；恢复原宽相对沉积态有sqrt(1+p)-1的几何失配。`ideal_free_misfit`只计算此理想估算。ITO加入后的变形须耦合求解，不人为施加+4.88%横向应变，也不把纵向整体压缩当所有厚度/方向均受压。

允许压缩屈曲、弯曲表面拉伸、横向回弹拉裂竞争；perfect-bond首版不回答界面脱粘机制。[S01–S05] 平膜并不保证理想均匀模型必然产生特定数量碎片，不能反复加弱点直到像照片。

## 扰动与后续状态

首个无缺陷工况无seed。已授权独立扰动对照时：出生保持先无扰动验证，后施加平滑局部触发，记录其外功与撤去后的约束；不把预制正弦形或持续U3顶推当自然成皱。稳定性模态求解须验证UEL支持，不自动套用普通壳*BUCKLE。

断裂出现后需要同时更新应力与d，不先完成无损伤变形再后处理删除。V1不模拟真实碎片独立碰撞/摩擦；接触成为主导时限定可信前缀。若以后授权再拉伸，继承释放得到的有效几何、应力、d/H/界面状态；不把碎膜重置成无应力完整膜。重拉和释放使用不同branch_id，不能在同应变去重时合并。
