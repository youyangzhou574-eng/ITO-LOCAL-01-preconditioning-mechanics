### 什么时候允许自动继续 analysis

如果唯一 datacheck 同时满足下面四条：

```text
A. 2021 parser accepts DISTORTION CONTROL=NO for this Explicit CPE4R case
B. PDMS hourglass effective setting remains the same baseline/default setting
C. ITO section/control state remains unchanged
D. no additional formulation/default change is reported
```

那么我接受下面这条证据链：

> 2021 实际安装身份  
> + 冻结的单变量输入差异  
> + 2021 原生 input processor/datacheck 对实际配置的闭合输出  
> + 2016→2025 跨版本文档一致性  
> + 2021 SIMULIA 官方案例对关键词语法/关联方式的版本内佐证

它**不是“找到了2021手册正文”**，要在报告中明确写成：

```text
2021_MANUAL_BODY_NOT_OBTAINED
SEMANTICS_QUALIFIED_BY_VERSION_LOCKED_NATIVE_DATACHECK
AND_CROSS_VERSION_DOCUMENTATION_CONSISTENCY
```

在这种情况下，**无需再次回来问同义许可，直接执行原合同中唯一 R2 analysis**。

反过来，如果 datacheck 只证明“关键词没报错”，但没有足够信息判断 hourglass 是否仍与 R1 等价，那么状态就是：


### analysis 启动后的原门保持

一旦进入 R2 analysis，仍然只看这个单因素问题：

> **关闭 PDMS distortion control 后，原来约 10% 的 ALLAE 和裂后响应是否发生系统性改变，同时几何是否仍有效。**

保持原门：

- `ALLAE/E* ≤ 5%`
- `ETOTAL drift/E* ≤ 1%`
- `ALLVD/E* ≤ 5%`
- ALLDC 按原生可用性报告，ITO 缺失绝不填 0
- 活动单元 Jacobian / overlap / BC / STATUS / 删除单调性
- 记录每个质量门的首次越界，而不是只报终值
- analysis 已启动后不自动重跑
- 关闭 distortion control 后若出现 PDMS 翻转、负体积或 fatal distortion，**这本身就是 R2 最重要的诊断结果之一，不允许重新打开控制“救算例”**
