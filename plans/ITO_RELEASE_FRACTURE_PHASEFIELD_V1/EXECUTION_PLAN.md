## 1. 本次明确选型，不再同时开发三条路线

**主线唯一确定为：有限变形薄膜 AT2 相场 + 三维 PDMS。**

1. S07 的公开扩展 UMAT 用来复现小应变断裂基准；不得用其最简无拉压分裂的 33 行版本计算压缩释放。
2. 正式薄膜使用参考 S04 的 8 节点 solid-shell UEL，含 EAS/ANS 防锁死、位移与相场耦合、厚度分辨的能量计算。没有作者源码时按文献和本设计实现，不把其他来历不明代码假称作者实现。
3. 生产模型不是普通 S4R 上加一个 UMAT，也不是把热场解释成真实温度。
4. 首版用 AT2 是为了先闭合有限变形断裂实现；**暂不开发有限变形 PF-CZM，也不开展整套 XFEM 并行路线。**AT2 的长度尺度与表观起裂强度有关，故首版只作候选参数机制诊断，不能预测真实工艺强度。
5. 首版界面完全粘接是明确的机制隔离假设。它只能回答“粘接不失效时能否发生膜内开裂”。缺少界面数据时不任意增加 CZM 参数；有证据表明脱粘主导，则转为下一独立版本，不用当前结果否定该机制。
6. 旧 coupon、FL1/FL2、R1/R2、无断裂 W0/W1 的 FAIL 和原始文件全部保留。新程序不得通过修改旧判门把它们变为相场验证。

**不再要求先得到三周期皱纹，才能研究断裂。**释放中的屈曲、横向回弹和膜内裂纹必须一起计算。

## 2. 已知目标、尚未知事实与首版默认边界

### 2.1 已知

用户当前明确要模拟：PDMS 预拉伸后沉积平坦 ITO，随后释放并研究断裂。初态不得预制周期皱纹、初始裂缝或低强度删除列。

### 2.2 不得补造为实验事实

实际释放夹持方式、实际样品长宽厚、当前主膜厚、沉积残余应力、真实 ITO 强度/断裂能、界面断裂参数、初始缺陷统计均未在本计划中获得新的实验确认。

### 2.3 为不中断方法开发，本版明确采用的诊断工况

- 单轴预拉伸 10%，侧面允许横向响应。
- **释放采用轴向夹具位移控制回到原长**；不是撤夹后的自由回缩实验预测。
- 两个 x 端面只约束/驱动 U1；不同时锁死整片横向收缩或所有端面 U2/U3。仅用最少约束去掉剩余刚体运动，并检查约束反力及端部效应。
- 不固定整个 PDMS 底面来强迫表面起皱；不在 ITO 膜面施加人为横向拉伸。
- 真实自由回缩如被确认，需另写零外力边界版本；不能把端距强压回原长称自由释放。

以上是本方案的假设，不是老师/用户已经确认的实验设置。可据此完成方法诊断；在写成实际样品预测前一次性核实实验边界，不必让用户反复回答数值实现细节。

## 3. 几何和离散

### 3.1 PDMS

优先使用 C3D8H 的三维有限变形混合实体，避免继承旧减缩积分 hourglass 问题。采用原 Mooney–Rivlin 卡，不引入 PDMS 损伤。若采用其他离散，须先给对照与差异说明，不能在生产失败后自动改成另一种本构。

### 3.2 ITO

- 采用专门的 8 节点 solid-shell 位移—相场 UEL。每节点 3 个位移自由度及 1 个相场自由度，共 32 个外部自由度；EAS 内部变量局部凝聚，不当作额外独立网格层。
- 参考 S04 实现 ANS/EAS；逐项写出锁死补偿、积分规则和凝聚后的切线。该部分是开发任务，不声称仓库已有可运行源码。
- 首个机械层沿厚度采用上下两层节点；至少比较 3 与 5 个厚度积分点。需要更多机械层时用独立对照，不将“一层 solid-shell”说成已经收敛。
- 相场可在厚度方向插值，但 ell/h 很大时不能宣称分辨了实际纳米表面起裂过程；重点是膜面 XY 的高损伤带及贯穿厚度的状态。
- ITO 物理底面与 PDMS 当前顶面重合；实体壳厚度朝外构建，不重复加 75 nm 壳偏置。

### 3.3 界面

完全粘接只传递位移。优先匹配网格共用底面位移节点，或经过验证的位移方程约束。**相场自由度不得跨界面传入 PDMS，也不得因 tie 温度/其他 DOF 而被强制为零。**不依赖未验证的 UEL 表面接触/原生 tie 支持。

### 3.4 网格与成本必须提前估算

- 正式 pilot 的 ITO 初始面内单元尺寸 a=0.25 μm，使 ell/a=3；这是起步分辨率，不是收敛结论。
- 验证网格 a=0.1875 μm 与 a=0.125 μm，保持物理尺寸、ell、材料、边界完全相同。
- PDMS 顶面要解析对应的位移传递；深部逐步放粗，若用非匹配网格先验证插值/约束误差。不得为节省内存把膜下几层严重粗化而不标注。
- 单 ITO 面网格约为 480×192 个面单元起步；精细耦合模型可能比旧无断裂 W1 更贵。不得宣传相场必然更快。
- 小型 6 μm 联调试样只验证出生、耦合和程序，不将其裂纹间距外推到 120 μm pilot。
- 所有生产网格先输出节点数、DOF、积分点、矩阵内存、磁盘估计，再依据实际 allocation/datacheck 调配资源。计算域缩小、ell 放大属于科学变更，不得冒充同一模型的资源恢复。

## 4. 本版方程约定：明确哪些来自文献，哪些是新实现

S04 是有限变形实体壳架构参考；下面的具体能量选择是本方案规定的客观有限应变扩展，并不宣称与 S04 每个算例的本构逐字相同。开发前完成公式—代码映射，复现原文和本项目迁移分开保存。

### 4.1 ITO 参考态与弹性驱动

ITO 的参考构型是沉积瞬间，而非 PDMS 预拉伸前。由该参考构型计算 F_f，令 U=sqrt(F_f^T F_f)，e=log(U)。首版采用 Hencky 应变的谱分裂：

- e_plus/minus：对 e 的主值取正/负部分；
- psi_plus/minus = lambda_L/2 * <tr(e)>_plus/minus^2 + mu * (e_plus/minus:e_plus/minus)；
- mu=E/[2(1+nu)]；lambda_L=E*nu/[(1+nu)(1-2nu)]；
- g(d)=(1-kappa)*(1-d)^2+kappa；
- psi_f(F,d)=g(d)*psi_plus(F)+psi_minus(F)。

从同一个能量推导应力及一致切线，包含有限转动和几何刚度；不得直接把小应变 C 矩阵当作有限变形切线。纯刚体转动 F=Q 时必须无弹性应力、无新损伤驱动力。

这是候选 ITO 弹性模型：覆盖大转动、以小材料弹性应变为主要适用区域，不代表大拉伸下真实 ITO 本构已标定。

### 4.2 AT2 裂纹能

以 ITO 沉积参考体积与参考梯度定义：

G_f = integral_Omega_f0 Gc * [d^2/(2*ell) + ell/2 * |Grad_X(d)|^2] dV0。

- 裂纹能不是 PDMS 体积损伤能；不得跨材料积分。
- shell/solid-shell 的厚度积分必须进入能量，不能把 N/mm 的 Gc 当成 N/mm^2 输入。
- 常见 AT2 模型/残余刚度、变量方向与 S07 对照；不混用完整变量为 1 的其他文献记号。

### 4.3 不可逆与耦合

采用 H_n=max 历史有效 psi_plus；每次 trial 从最近已接受增量的 H_n、d_n 开始。相场残差按 g'(d)*H + Gc*(d/ell - ell*Laplacian_X(d)) 构造；H 在加载分支内的导数与切线处理必须明确。

生产求解采用整体耦合 Newton，参考 S04 的耦合/凝聚框架。若使用历史场引起非对称切线，按实际数学形式声明，不能强行置对称。每个接受增量检查 0<=d<=1 及不可逆性；容许浮点级误差，不允许用后处理裁剪掩盖持续愈合或越界。源策略无法满足该门时，修正算法并先回到基准验证，不盲跑完整模型。

- 拒绝/回退增量不得提交 trial H 或 damage。
- 不使用全局可变数组把不同积分点/CPU 的状态混在一起。
- 不把 H 当作实际储存弹性能计算能量账。
- 不用各向同性退化把压缩刚度全部删除；但谱分裂并不等于真实裂面接触。

### 4.4 弯曲与压缩限制

在厚度积分点先构造完整 F/应变，再进行拉压分解和损伤驱动积分。不得仅用中面平均应变判断。

纯静水压缩测试应无张开型裂纹驱动。自由单轴压缩有横向应变，不能用“轴向受压”代替“所有主应变都负”。若候选谱分裂在试验性压剪路径出现不合理损伤，应明确模型限制，不称其已验证真实压碎。

本版未实现裂面摩擦滑移、碎片碰撞和脱粘后的表面接触。因此到显著裂面闭合/碎片大滑移阶段，可信范围需单独判定；不能因为未出现单元删除就宣布接触物理正确。

## 5. 工艺路径：新 W0→新 W1，不从旧坏几何续算

### W0：裸 PDMS 预拉伸

ITO 不参与承载。以新模型的自然几何施加 10% 轴向预拉伸，横向自由响应。端面设置与第 2 节一致。保存实际变形顶面、应力、自然参考节点、连接和足够的超弹性状态见证。

### W1/BIRTH：在当前顶面加入平坦新膜

- 导入新 W0 的 PDMS 状态，采用经最小算例验证的 STATE=YES / UPDATE=YES 路线；只导入受支持的 PDMS 原生单元。
- ITO UEL 是 W1 中新增的单元，其参考节点由真实 W0 当前顶面生成，d=0、H=0，不导入虚构的旧 ITO 相场状态。
- 在 BIRTH_HOLD 保持 W0 端距，核对 PDMS 几何/应力连续、ITO 无应力与全量分量映射。
- 先用小型联调验证该路线。若版本/导入确实不支持该组合，提交实际报错及最小复现，不把 UPDATE=YES 换成预设应力或热膨胀而不说明。
- 不要求 W0 与 W1 的原生 ALLSE 数字逐字相等；依据第 7 节统一物理定义和同 W1 增量收支。

### W1/RELEASE：从开始释放即允许损伤

用无量纲释放进度 r∈[0,1]：L(r)=L_d-r*(L_d-L_0)，其中 L_d 是实际 W0 末端距。主试样名义 132→120 μm；始终用实际节点端距记录应变。

- 侧向变形由力学平衡产生，不给 ITO 人工指定 +4.88% 横向拉伸。
- 初始 d=0，无初始裂纹、弱化列、缺口或随机强度场。
- BIRTH 阶段无几何缺陷/seed。首个生产试算不预置周期波形，也不预先强迫起皱。
- 允许自然几何非线性与断裂共同演化；出现均匀损伤或未见局部裂纹也是真实模型输出，不能通过换 seed 直到得到“碎片图”。
- 若严格对称模型需要扰动才能识别分支，必须另记录单一、平滑的扰动对照及卸载功，并证明结果不由其决定；该对照不属于首个无缺陷主工况的暗中修改。
- 使用自动增量/回退；初始最大 r 增量 0.01，损伤增长区缩小。接受增量的 max|Delta d|以 0.05 为分辨率目标，突然跳裂仍保留括区及步长敏感性，而非修改物理能量强迫连续。
- 到 r=1 或明确科学/数值停止条件后交付；没有输出的最后状态不得补图。

再拉伸、循环、电阻不属于本版必须完成的任务；若之后增加，应继承损伤和应力，不重置为无应力完整膜。

## 7. 能量、出生和几何验收

以下是本项目数值验收阈值，不是文献声称的普适实验精度。先在小算例上证明量的定义可计算，再用于 production。

### 7.1 出生与状态转移

- PDMS 节点坐标映射 max 误差 <=1e-7 mm；应力相对 L2 <=1e-3，并报告绝对量、分量及参考零场。
- 新膜初始平面拟合残差 p99 <=5e-7 mm。
- 新膜完整应力张量各独立分量的绝对 p99 <=0.5 MPa；完整应变各分量 p99 <=5e-6；相场及历史值应符合初始化。
- 各张量按实际分量标签解析，不取“前三列”冒充膜内 11/22/12。
- 几何+应力连续不足以替代超弹性切线资格：V03 必须再做小增量扰动，比较导入前后的反力增量和储能变化。

### 7.2 几何

分别检查原参考和当前单元映射。对实体/实体壳至少在实际积分点、中心及必要角点检查 Jacobian；记录最小值、元素标签和局部位置。确认负 J 后该帧及之后不能作为可信材料路径。检查节点顺序、单位、连接映射以排除解析错误，但不把确认的负 J 靠阈值放松改为 PASS。

未评估的碰撞/接触写 NOT_EVALUATED，不从“没有找到候选对”推导真实接触无问题。科学有效前缀采用逐帧累计合格，不越过失败帧重新恢复。

### 7.3 能量

统一输出：PDMS 弹性能、ITO 退化后弹性能、ITO 裂纹能、外力功、数值稳定化/其他数值耗散，存在动能时另列。首版无界面断裂能，不填出虚构的 CZM 能量。

W1 内以真实 BIRTH_HOLD 末态为增量起点：

Delta W_ext = Delta U_PDMS + Delta U_ITO + Delta G_fracture + Delta D_num (+ Delta K，若实际存在)。

- ITO 弹性/裂纹能按 UEL 实际积分计算；核对 Abaqus ENERGY/ALL* 的包含关系，禁止与 sidecar 重复相加。
- 断裂能不能写入 artificial-energy 槽后再以 5%门拒绝，也不能扣掉它让能量闭合。
- PDMS 储能需要原生区域能量或可追溯的自然参考 F/本构积分。保留 W0 自然参考网格及映射，是为了核验导入后的储能；不能任意补一个常数强迫跨 job 相等。
- 外功包含所有实际施加载荷/位移 DOF；有转动或扰动时相应广义功不能漏掉。用原生 U/RF 与加载记录交叉核查。
- 归一化采用本 W1 的固定正参考 E_ref=max(U_PDMS_birth+U_ITO_birth, max|Delta W_ext|, Gc*t_f*L_0)，不借用旧 E*。定义在首个结果前写入配置；近零段同时报绝对误差和 NOT_EVALUABLE。
- 总增量收支残差/E_ref <=1% 为目标门；数值耗散/E_ref 目标<=2%，>5%不作物理资格通过。真实断裂能没有“必须低于5%”限制。
- 原生来源不足则 ENERGY_REFERENCE_UNRESOLVED，禁止补0或删除这一栏；解决最小缺失后再解释物理。

### 7.4 求解稳定化

基准按作者原设置复现。新生产模型优先静力几何非线性、整体耦合 Newton、自动cutback；不默默叠加稳定化。确需稳定化时，以独立输入记录并安排减半对照；它不是能量不合格后不断增大阻尼的通行证。切换 Explicit、Riks、物理粘弹性或增加惯性属于新方案变更。

## 8. 裂纹、片段和形貌输出：不拿相场带宽当实际裂缝宽

至少输出以下物理分级：

1. `DIFFUSE_DAMAGE`：非零 d，仅为弥散损伤；不叫第一条宏观裂纹。
2. `LOCALIZED_DAMAGE_OBSERVED`：首次出现 d>=0.5 的局部带，保存前后实际增量括区、位置与分量应力；0.5 是观察阈值，不是材料常数。
3. `HIGH_DAMAGE_BAND_OBSERVED`：d>=0.95 的连通带。对 0.90/0.95/0.99 同时给出后处理阈值敏感性，不重跑求解。
4. `THROUGH_THICKNESS_BAND`：整个厚度均有对应高损伤连续性；不能只看某个表面或厚度平均 d。
5. `FRAGMENT_CANDIDATES`：由贯穿带切分出的完整材料连通分量，是数值候选片段，不自动等于有摩擦接触的自由碎片。

图表采用真实膜面 XY + 3D 当前形貌，至少包括出生、局部损伤开始、首个贯穿带、若干释放检查点及真实最后有效帧。同步画实际端距、释放进度、反力、裂纹能和损伤指标。

裂纹长度/密度采用明确的参考面积、骨架算法和阈值；片段尺寸受 ell、网格、边界和材料非均匀性影响。首版无随机场，不声称逐条复制实验裂纹。初始平面图用固定有物理意义的高度范围，避免把1e-6 nm色标噪声解释成褶皱。

同应变比较仅在同一单调加载分支内，精确重复保留 LAST；禁止跨释放/重拉分支去重。真实场帧不以时间插值生成“新原生场”。

## 9. 不能由本版直接宣称的结论

- “ITO 被压碎”不能只依据总体轴向压缩：需报告局部拉伸/弯曲和横向应力驱动；压剪粉碎机制未标定。
- 完美粘接下未出现开裂，不证明实际存在脱粘的样品不会开裂。
- d 的宽度不等于裂缝张开宽度；d 不下降不等于已实现接触。
- 150 nm 方法 pilot 不替代本工艺膜厚、强度、界面、导电或循环实验。
- 单次出现漂亮网络不等于网格/长度尺度/扰动独立。
- 原二维删除结果不作新相场裂纹路径的真值；原大模型无效帧不作初始条件。

## 12. 工作预算、恢复与连续性

**上传此计划不启动服务器。**用户让桌面“按此方案执行”后，以下是该版本建议采用的独立研发工作预算；单纯“读取”不是派发任务。已有用户/机构资源上限优先，涉及新增收费资源需单独批准。

|---|---:|---|

|合计|32|新包累计，不继承旧额度|

- datacheck 共48次上限；不得用同输入机械地反复试运气。普通Python/Fortran单元测试、文件验证、可恢复的只读连接不按native分析次数计费。
