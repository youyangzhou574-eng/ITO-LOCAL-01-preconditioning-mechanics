# 实施补充：五类最容易造成假通过的问题

本文件与 EXECUTION_PLAN.md 一起执行；不改变首版科学路线，也不启动任何计算。以下是实施核查，不是要求重复旧全文搜索。

## 1. 位移收敛不等于相场收敛

UEL 每节点仍为3个位移+1个相场自由度。相场推荐映射到DOF11；这只是数值标量，不是真实温度。实际分析procedure、LFLAGS、活跃自由度和收敛检查必须在最小UEL中核对。

不能假设Standard的某个静力procedure自动对任意用户标量给出正确收敛判据。2025官方UEL说明区分了静力、热和耦合过程的自动检查范围；2021执行须用实际小算例建立接口证据，不需要为每个问题寻找整本旧商业手册。

生产前必须独立审计位移残差、装配后的相场残差以及相场增量。独立残差的量纲、归一化和阈值先写入接口协议。推荐目标为各场归一残差<=1e-6、最后迭代max|Delta d|<=1e-6；静止或零驱动情形同时报告绝对量。不在UEL内部把尚未收敛的trial状态写成已接受历史。

测试：人为制造“机械残差小、相场残差大”的输入必须拒绝；不能只依赖exit0。若使用DOF11的具体procedure不能可靠完成耦合检查，应在P2内修正接口并重验，不暗中把相场当作未求解的预定义温度。

官方技术入口（2025，不能标成2021实证）：
https://docs.software.vt.edu/abaqusv2025/English/SIMACAESUBRefMap/simasub-c-uel.htm

## 2. 全积分PDMS也不等于没有数值稳定项

C3D8H是本版选型，但全积分超弹性单元也可能包含弯曲稳定化等算法。不得因没有减缩积分hourglass就把全部人工能量声明为零。

保留实际默认控制，核对原生能量输出和可识别控制信息；发生数值耗能超限时按主计划判定。尚未取得的算法状态仍标未确定，不从ALLDC=0推断控制关闭。

测试：注入非零数值耗能的合成history，审计器必须累计而非漏记；压缩/弯曲小例必须通过能量与形状核查。

官方技术入口（2025）：
https://docs.software.vt.edu/abaqusv2025/English/SIMACAEELMRefMap/simaelm-c-sectioncontrol.htm

## 3. ITO出生参考态和PDMS预应力不能相互清零

V03必须同时核对几何、应力、切线和小增量功；不是只有“坐标一样”就通过。W0自然坐标、W1更新坐标及连通映射要同时保留。

测试：错误地将PDMS清为无应力，或将其预应变赋给新ITO，两种错误都应被检测。相场d/H只能在新膜出生初始化一次，不能每个step重置。

## 4. 局部DOF/输出/并行历史不能串线

DOF11不通过界面约束传入PDMS；共享位移节点不等于共享材料内部变量。UEL内部索引、EAS内部变量、积分点、厚度方向、上下表面及输出编号必须有固定表。

测试：相邻单元不同损伤、不同积分点历史、交换上下表面、重复主应变、拒绝增量回滚、单CPU/多CPU对照。实际S/SE等按标签取值，不按数组前三列推定含义。

## 5. 输出缺失与空分母必须保留为未知

时间对应以step+native increment为主，浮点时间比较考虑打印与存储表示；不能伪造accepted increment。支持早停后的实际帧序列，而不是要求必须有预想的4001帧。

未生成XY图、未输出UEL能量、未构造相场连通图时保持NOT_EVALUABLE；不填0。释放与后续重拉是不同分支，不合并去重。

测试：已接受增量但时间float32表示不同、漏帧、缺字段、近零能量、同应变不同加载分支、损坏文件与截断运输均有明确拒绝或保留未知行为。

## 验证与更改边界

这些接口/解析修正可在P0–P2阶段内连续进行，受主计划预算和测试约束，不逐条请示同义许可。它们不能用来改变材料、边界、fracture模型或能量验收门。主工况若被真实几何/物理问题限制，仍须保留失败和有效范围。
