## 最终选型

**Abaqus/Standard + 三维超弹性 PDMS + 有限变形 solid-shell AT2 相场 UEL；首版界面完全粘接。**

目标是从初始平坦、完整的 ITO 开始，在 PDMS 释放过程中直接计算膜内损伤、裂纹带与贯穿情况。不得继续用 fracture OFF 的连续皱纹模型代替，不先算完皱纹再删除材料，不从旧无效几何续算。

本版只先闭合有限变形断裂方法。AT2的强度与长度尺度有关，旧265MPa不作为独立强度门；材料参数仍是候选值。界面CZM、摩擦接触、自由碎片运动、PF-CZM强度标定、XFEM平行路线、电阻与再拉伸均不偷偷加入首版。

## 启动顺序

**P0来源与方程/配置 → P1作者断裂基准 → P2有限变形实体壳与出生验证 → P3三维释放断裂 → P4必要网格/步长/长度尺度验证。**

P0–P2通过之前，不提交大规模全膜计算。P1可以有二维程序基准，但真正的P3必须有XY膜面和三维变形；不能把前者交付成后者。

首版诊断假设为10%单轴预拉伸、夹具位移控制回到原长、横向由模型自由响应、平坦无残余应力ITO出生、完全粘接。该假设不是已确认实验事实。实际撤夹自由回缩、不同膜厚或界面脱粘，需要明确改版，不能在结果解释中偷换。
